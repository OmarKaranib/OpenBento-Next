# OpenBento WebMCP

The judge-facing WebMCP specification is maintained at the repository root:
[WEBMCP_SPEC.md](../WEBMCP_SPEC.md).

It documents the live URL, all 13 registered tools, shared persistent domain
authority, ownership and Frame-membership behavior, and local/judge testing.
Keeping one canonical copy prevents the stale implementation-phase language
that previously diverged between these paths.
